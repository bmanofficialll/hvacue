MODERNIST BUILD · TURN 2

Rebuilt on the Modernist system: light ground, one red accent, zero radius, 2px rules, Archivo throughout. Red now carries a single job — abnormal.

WHAT CHANGED

Readings now live on one gauge set — every channel on a single card, tap any cell to key it in, no wizard. Provenance moved to a small red square beside a value; tap it for the sources sheet. Depth is AUTO and switches itself once you start working fast.

Two scenarios run on the same engine: the water-cooled chiller and a 4-ton R‑410A split on a no-cooling call. Pick either from the home screen.

TRY

Key in a supply air temperature above return air, or 300 PSIG on the chiller — the data check refuses it. Leave the gauge set empty and the engine refuses to show a confidence number at all.

The Android frame is the same session on platform chrome — one codebase, two shells.
